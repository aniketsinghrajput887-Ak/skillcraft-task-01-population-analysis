# Task 01: India Population Distribution Analysis

## Project Overview
This project analyzes the distribution of India's population across different age groups using Python. A bar chart is created to visualize the percentage of population in each age group.

## Objective
The main objective is to understand population distribution through data analysis and graphical visualization.

## Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code

## Dataset Description
The dataset contains two columns:
- Age_Group
- Population_Percentage

It includes five age groups:
- 0–4 years
- 5–9 years
- 10–14 years
- 15–59 years
- 60+ years

**Note:** The CSV used in this project is a sample dataset prepared for this analysis. Its figures should not be treated as independently verified official statistics.

## Data Analysis
The following operations were performed:
1. Imported the required Python libraries.
2. Loaded the CSV dataset using Pandas.
3. Inspected the dataset.
4. Checked missing values.
5. Checked duplicate records.
6. Calculated statistical summaries.
7. Calculated the total population percentage.
8. Created a bar chart using Matplotlib.

## Key Findings
- The 15–59 years age group has the highest share at 66.3%.
- The 5–9 years age group has the lowest share at 7.9%.
- The dataset contains no missing values.
- No duplicate records were found.
- The total population percentage is 100%.
